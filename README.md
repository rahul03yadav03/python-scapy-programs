# Python Scapy Programs – Network Testing & Monitoring

# About This Project
- This repository contains multiple Python programs built using the Scapy library.
- The purpose of this project is to practice and understand:
  - Packet crafting and manipulation
  - Network scanning concepts
  - Port detection and connectivity testing
  - ARP spoofing simulation and detection
  - DNS query monitoring
  - HTTP traffic analysis
  - Subnet discovery using ARP
  - ICMP ping testing
  - Logging and monitoring IP traffic
  - This project was created as part of my cybersecurity learning journey.
  - During the process, I used ChatGPT to help clarify some of the more difficult Scapy concepts and to assist in generating algorithmic structures. This allowed me to better understand how Scapy works and apply it effectively in my programs.


# Project Description
- Through this project, I explored how network reconnaissance and monitoring works using Scapy and how it can be automated with Python.
- I implemented different types of programs including:
  - Offensive testing (ARP spoofing, SYN scans, ICMP ping)
  - Defensive monitoring (ARP spoof detection, DNS query logging)
  - Traffic analysis (HTTP sniffer, IP monitors)
  - Utility scanning (ARP subnet discovery, port status checker)
- The goal was to understand how network information is gathered, analyzed, and detected in a structured and programmatic way.


# Objectives

- Learn how Scapy works for packet manipulation
- Understand TCP/IP and ARP concepts
- Detect running services and suspicious activity
- Monitor DNS queries and HTTP traffic
- Perform host discovery in a subnet
- Log source/destination IPs for analysis
- Practice safe and ethical network testing

# How To Run
- Open terminal in project folder and run any script:
  - python file_name.py
  - Follow the prompts for IP addresses, ports, or subnets depending on the script.

- Running services (basic detection)

- HTTP traffic details
- Source and destination IPs
