 │    ├─ TCP Connectivity Test (SYN Scan)
 │    │    → Send SYN packet
 │    │    → Check flags:
 │    │         - SYN-ACK = Port Open
 │    │         - RST-ACK = Port Closed
 │    │         - No response = Filtered

 │         → Verify network connectivity

 │    │
 │    └─ DNS Query Monitoring

 │         → Log source IP and domain name
 │

 │    ├─ HTTP Packet Monitor

 │    │    → Display IPs and ports
 │    │

 │    │    → Capture packets for chosen IP
 │    │    → Display TCP/IP details
 │    │
 │    └─ Source/Destination IP Logger
 │         → Capture packets
 │         → Display source and destination IPs
